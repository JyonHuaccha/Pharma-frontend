## Resumen de ejecución

- Casos registrados: 25 (16 base, 5 propios y 4 del aviso).
- Pasa: 23. Pendiente: 2 (S-04 e I-02). Fallas observadas: 0.
- Pruebas de frontend: 114 de 114 pasan en 21 archivos; compilación de producción finalizada.
- S-04 e I-02 requieren captura manual en navegador integrado. Durante esta sesión la aplicación informó que el uso del navegador local estaba deshabilitado en la configuración de Work.
- Para I-02 se probó la rama de error de conexión con el cliente HTTP simulado, pero no se obtuvo la captura manual con DevTools que pide la consigna. Para S-04 no se midieron dos pestañas.
- El JWT de tres minutos se usó solo en la prueba temporal. El archivo de configuración del backend conserva 60 minutos. La cuenta `supervisor` quedó restaurada con ALMACENERO y VENDEDOR.

## Evidencia backend resumida

Las respuestas reales del backend se resumen en `evidencias/s11/api-resultados-s11.json`: credenciales inválidas/inactivas devuelven el mismo 401 genérico; el token alterado produce 401 en Ventas; la acción no autorizada produce 403; el cambio temporal de roles se revirtió y verificó. `evidencias/s11/api-expiracion-s11.json` registra la expiración firmada temporal de 180 segundos. Ninguno de esos resúmenes contiene JWT.
